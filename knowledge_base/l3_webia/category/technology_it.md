# Kategori 12 · Technology & IT — WEBIA

## 1. Profil Kategori
Solusi website bisnis profesional untuk industri teknologi informasi, software house, pengembang aplikasi mobile/web, konsultan IT, agensi UI/UX, dan tech startup.
- **Slug**: `technology-it`
- **Simbol**: ⚡
- **Target Bisnis**: Software house, digital product studio, IT consultant, penyedia solusi cloud & SaaS, web & mobile app developer.

## 2. Fitur Kunci & Modul Rekomendasi
- **Showcase Portofolio Proyek IT**: Menampilkan studi kasus proyek aplikasi web/mobile dengan tampilan mockup, deskripsi tantangan & solusi, serta tech stack yang digunakan.
- **Breakdown Tech Stack**: Menampilkan logo & teknologi modern yang dikuasai (Laravel, React, Vue, Flutter, Python, Node.js, AWS/GCP).
- **Formulir RFP / Request for Proposal**: Form pengumpulan spesifikasi kebutuhan sistem klien untuk estimasi penawaran harga software.
- **AI Tech Scoping Assistant**: Chatbot konsultan yang menanyakan ruang lingkup proyek klien dan merekomendasikan estimasi paket & arsitektur dasar.
- **Blog & Engineering Insights**: Artikel rilis teknologi, update arsitektur, dan studi kasus pengerjaan sistem.

## 4. Rekomendasi Paket Website WEBIA
- **Paket Pulse (Rp899.000)**: Cocok untuk software engineer / freelancer studio yang membutuhkan landing page portofolio showreel dan form kontak kerja sama.
- **Paket Nexus (Rp1.499.000) ★ Rekomendasi**: Sangat pas untuk software house berkembang yang membutuhkan Dashboard CMS mandiri untuk mempublikasikan proyek klien baru, studi kasus, dan update tim tanpa perlu koding ulang website.
